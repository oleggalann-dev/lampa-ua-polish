# UA-полірування для Lampa / Сяйва

Плагін для [Lampa](https://github.com/yumata/lampa) і [Сяйва](https://siaivo.github.io):

- **Українські рядки**, яких бракує плагінам. Lampa без перекладу `uk` показує `ru`; зокрема Bandera Online записує український переклад під кодом `ua`, тож «Смотреть онлайн», «Нет истории просмотра» і «Видео» лишалися російською.
- **Шрифт Inter** (латиниця + кирилиця) замість Segoe UI.
- **Фокус як в Apple TV**: картка піднімається, збільшується, отримує тінь і легкий відблиск замість білої рамки.

- **Миттєвий перегляд**: «Дивитись» без меню «Джерело». Фільм одразу вмикається з найкращої версії UAFilms; якщо там порожньо — відкривається Bandera, далі торренти. Серіал відкривається на наступній серії (позначка «Далі»), сезони — вкладками над серіями, після повністю переглянутого сезону — одразу наступний. Утримайте OK на «Дивитись», щоб вибрати джерело вручну.

Шрифт, фокус і миттєвий перегляд вмикаються та вимикаються в **Налаштування → UA-полірування**.

## Torrentio

Окремий плагін `torrentio.js`: одна кнопка «Torrentio» замість «Торренти» для українського й англійського контенту.

- Джерела: [Torrentio](https://torrentio.strem.fun) (без російських трекерів) і Toloka через парсер LampaUA.
- Сезони й серії окремими екранами: лише ті, що вийшли, з назвою, датою, кадром і прогресом перегляду.
- Список релізів з вкладками «Українська / English / Усі»; 4K і файли понад 15 ГБ сірі.
- Із паку сезону вмикається одразу потрібна серія (через TorrServe на `127.0.0.1:8090`, якщо в Lampa не задано інший).
- Toloka-роздачі приватні: потрібен ваш ключ (passkey) у **Налаштування → Torrentio**.
- **Налаштування → Torrentio → Джерело**:
  - «Pirate Bay (англійською) + Toloka» (типово) — англомовні релізи з Pirate Bay і українські з Toloka, вкладки «Українська / English»;
  - «Лише The Pirate Bay (англійською)» — без Toloka і вкладок;
  - «Усі трекери + Toloka» — усі трекери Torrentio, крім російських.
- Pirate Bay шукається і через Torrentio, і напряму через API Pirate Bay: Torrentio запізнюється з новими релізами.
